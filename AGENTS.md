# Agent instructions

- Make every commit in this local repository with Git user name `developer` and email `developer@extabrain.app` for both author and committer. Set these values in the repository's local Git configuration before committing. Do not use a different identity or add an agent co-author.
- Keep each skill self-contained under `skills/<skill-name>/` so it can be installed directly with `npx skills`.
- Validate changes to a skill before publishing them, including its frontmatter and local reference links.
